# Antigravity Design & Development Rules

These rules govern the development of the Job Management SaaS platform to ensure the visual hierarchy, micro-animations, and UX feel exactly like a premium Apple/Linear/Notion-grade product.

## 1. Visual Hierarchy & Spacing (8px Grid)

- **Grid Discipline**: All margins, paddings, gaps, and heights must be multiples of 8px (`space-y-2` (8px), `p-4` (16px), `gap-6` (24px), `py-8` (32px), `mb-10` (40px)). Never use arbitrary numbers.
- **Whitespace**: Leave generous margins. Avoid packing components tightly. The interface must feel airy.
- **Borders**: Extremely fine, 1px borders using `#E8EAF1` (`border-bg-border`). Do not use heavy borders.
- **Shadows**:
  - Cards: `shadow-[0_10px_40px_rgba(15,23,42,0.06)]`
  - Hover: `shadow-[0_20px_60px_rgba(15,23,42,0.12)]`
  - Floating items (dropdowns/modals): `shadow-[0_30px_80px_rgba(15,23,42,0.16)]`
  - Primary button: `shadow-[0_8px_30px_rgba(108,99,255,0.18)]`

## 2. Color System

Apply colors strictly using these design tokens:

- **Primary Background**: `#F6F7FB` (SaaS Dashboard layout background)
- **Secondary Background / Card**: `#FFFFFF` (Sidebar is `#FBFBFD`)
- **Accent Purple**: `#6C63FF` (Hover: `#5B52F5`, Light: `#F2F1FF`)
- **Alerts**:
  - Blue (`#4F8EF7`), Green (`#34C759`), Orange (`#FFB547`), Red (`#FF5C5C`), Gray (`#8A94A6`)
- **Text Hierarchy**:
  - Title: `#17181C` (Weight: 600/700)
  - Heading: `#23262F` (Weight: 500/600)
  - Body: `#646B7A` (Weight: 400)
  - Caption: `#98A2B3` (Weight: 400)

## 3. Radii Constraints

- Window outline / App container: `rounded-[32px]`
- Cards: `rounded-[24px]`
- Buttons & Input Fields: `rounded-[18px]`
- Badges: `rounded-full` (999px)
- Avatars: `rounded-full`

## 4. Typography Rules (Inter & SF Pro Display)

- Page Title: `text-[36px] font-bold tracking-tight text-txt-title`
- Section Heading: `text-[22px] font-semibold text-txt-heading`
- Card Title: `text-[18px] font-semibold text-txt-heading`
- Body Text: `text-[14px] font-normal leading-relaxed text-txt-body`
- Caption Text: `text-[12px] font-normal text-txt-caption`
- Sidebar/Nav: `text-[15px] font-medium`

## 5. Animation (Framer Motion & @dnd-kit)

- **Spring Physics**: Use spring transitions rather than linear or ease curves:
  `transition={{ type: "spring", stiffness: 350, damping: 25 }}`
- **Card Drags**:
  - Scale up slightly to `1.03`
  - Rotate by `1deg` (subtle premium slant)
  - Darker soft shadow (`shadow-floating`)
  - No snapping. Smooth tracking.
- **Button Interactions**: Scale down to `0.98` on active click; scale up to `1.01` on hover.

---

_Every screen must look like it was designed by Apple's Human Interface Design team._
_When uncertain, choose elegance over decoration. Prioritize whitespace, alignment, typography, and motion._
